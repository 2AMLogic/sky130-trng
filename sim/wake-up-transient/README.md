# wake-up-transient

Issue #216. Analog wake-up transient of the committed pre-layout
`design/ro_array_core.spice` against DR-0004's 1024-sample start-up window (20.48 ms at
DR-0003's 50 kbps). Everything here is **simulation-derived and provisional until silicon**.

**Status: PARTIAL.** The PVT grid (54 deterministic units + 3 x 32 noise seeds) is fully
generated by `make-requests.py` but could **not** be run: the Spot batch fleet rejected it
(see "What was and was not run"). The committed transistor evidence is two single-corner
local debug probes; the margin statement rests on the behavioural leg calibrated on earlier
transistor records at all 18 calibrated PVT points.

| File | Role |
|---|---|
| `testbench/tb_wakeup_array.spice`, `tb_wakeup_array_ramp.spice` | deterministic cold-start decks (enable-gated wake / 1 us supply ramp without gating) |

## Margin statement vs DR-0004's 1024-sample start-up window

(Full text and per-corner table: `records/20261009-093500-e57ad27.md`.)

- **Analog settling** is nanoseconds (2.6 ns / 4.0 ns at the one probed corner, the slowest ss / -40 C / 1.62 V),
  about 10^-4 of one 20 us sample interval, so the rings oscillate at steady frequency before the first 50 kbps
  sample. Only the probed corner is measured; the other corners are expected faster (ring periods are shorter) but
  this is not yet evidenced.
- **Statistical stationarity** is the binding effect: after the enable every ring restarts from the same stopped
  state, so the raw bit is not stationary across wake-ups until jitter has spread the phases. Worst case over the
  18 calibrated corners, samples to reach a worst-case bias bound B: B <= 0.2071 (H >= 0.5 bit) in 12; 2^-10 in 47;
  2^-20 in 92; **2^-40 in 181 (ss / -40 C / 1.62 V)**. The 1024-sample window therefore covers mixing to 2^-40 with
  a margin of **5.7x** (21.8x to 2^-10). The DR-0004 start-up test passed on all simulated wake-ups in both arms
  and cannot detect this non-stationarity (it counts those samples as healthy). Mixing time scales as 1/sigma_1^2, so
  a 2x error in the injected-noise-derived jitter changes the 5.7x to 1.4x - still adequate, but thin.
- **Conclusion**: adequate under the model; **no decision-record change is indicated**, so none was filed. The raw
  path is never gated, so raw-path consumers should discard roughly the first 50 to 200 samples after a wake-up.
  This conclusion is provisional until silicon, and until the transistor noisy leg above is run to cross-check the
  behavioural mixing time.
