**Disclosures** (quoted in the record JSON; envelope-verbatim in
`pex-report.json`):

- **`extraction.model` limits** — first-order lumped-RC: one series R per
  net terminal (star), net-to-ground C plus *vertical-overlap* coupling C
  only; **no lateral sidewall coupling** (no `--critical-net`), no
  distributed RC ladder (no `--distributed-rc`), quasi-static
  (frequency-independent R and C). Delay-relevant interconnect is
  therefore a lower bound in fidelity terms, and the ring-period deltas
  above are what this model reports — a finer coupling/ladder model would
  move them, not the comparison's integrity.
- **`body_bias`** — `status: "biased"`: every device body in the extracted
  netlist has a DC path (`unbiased_device_count: 0`); no `--tie-net` was
  needed, so the extracted-side numbers carry no synthesized body tie.
- **PDK install divergence** — the extraction resolved sky130A through the
  host search root (open_pdks `f6eeac7…`), *not* the volare install
  `sim/pdk.json` / `design/pdk.json` pin (`c6d73a35…`). Both legs of
  every row ran on the same fleet model library
  (`models_lib_sha256 48de7c67…` in every `resp-*.json`), so each delta
  is self-consistent; absolute values carry the fleet library pin.
- **Deck** — curated sky130 deck `sha256:f78d2c3c…` on klt
  `0.9.3.dev2575+g6bd18bbc8637` (dev build; `deck.released: false`).
- **`--measure-command` mode** — the harness measured each leg; `klt pex`
  itself picked both netlists, ran the harness once per side, and computed
  every delta row. Mode, argv, per-side netlists and exit statuses are in
  the envelope's `measurement` block.
- **Provisional** — simulation-derived, provisional until measured on
  silicon; entropy/health verdicts live in `signoff/characterization-report.md`
  (item 8), not here.

**Reproduction.**

```sh
klt pex layout/sampler_core/sampler_core.gds --deck sky130 --pdk sky130A \
  --measure-command 'python3 sim/pex-sampler-core/harness/pex-measure.py' \
  --reference-netlist design/sampler_core.spice --flatten-schematic \
  --pins en1,en2,en3,en4,vddr1,vddr2,vddr3,vddr4,vdd,vss,clk,rst_n,raw_bit,raw_valid,ring_bit1,ring_bit2,ring_bit3,ring_bit4 \

  --measure-timeout-s 7200 -o <outdir>/sampler_core.extracted.spice \
  --outdir <outdir>/pex --envelope-out <outdir>/pex-report.json --format json
```
