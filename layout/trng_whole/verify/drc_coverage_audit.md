## Verdict conditions

- `vacuous-confirmed` for `angle`: the one layer the rule reads has geometry == 0 in the flattened stream.
- `vacuous-confirmed` for `ongrid`: the one layer the rule reads has geometry == 0 in the flattened stream.
- `vacuous-confirmed` for `width`: the one layer the rule reads has geometry == 0 in the flattened stream.
- `vacuous-confirmed` for `space`: the one layer the rule reads has geometry == 0 in the flattened stream.
- `vacuous-confirmed` for `enclosing`: at least one of the two layers the rule reads has geometry == 0 (the check needs both).
- `vacuous-confirmed` for `separation`: at least one of the two layers the rule reads has geometry == 0 (the check needs both).
- `residual`: every layer the rule reads has geometry > 0, yet klt lists the rule as inapplicable.
- `unresolved`: rule id not in the pinned deck; or a deck layer name not resolvable to exactly one stream layer/datatype that the pinned DRC run also read (drc.json coverage.deck_layers); or a check kind / layer count outside the kinds above. Never forced to vacuous-confirmed.
- unruled `present-unruled`: geometry > 0 and klt's annotation flag is false: drawn shapes that no curated rule reads.
- unruled `text-or-marker-only`: flattened_shapes > 0 and (geometry == 0, i.e. text objects only, or klt's annotation flag is true).
- unruled `unresolved`: listed by klt drc as in the stream but klt layers reports no shapes for it.
